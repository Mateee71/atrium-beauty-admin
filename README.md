# Atrium Beauty Admin

> [!IMPORTANT]
> Ez a repository kizárólag saját fejlesztésű, portfólió- és tesztprojekt.
> Nem valós, éles rendszer, nem használható valódi időpontfoglalásra vagy üzleti működésre.
> A projektben megjelenő felhasználók, időpontok és statisztikák teszt- vagy mintaadatok.

Modern időpontfoglalási és szalonkezelő rendszer az Atrium Beauty számára.

## Funkciók

- Interaktív napi, heti, havi, éves és agenda naptár
- Időpontok létrehozása, szerkesztése és törlése
- Szakemberek és szolgáltatások kezelése
- Egyéni és globális elérhetőségi időszakok
- Dátumhoz kötött elérhetőségi felülírások
- Beágyazható publikus foglalási felület
- Automatikus visszaigazoló, módosító és lemondó emailek
- Dashboard kimutatások és diagramok
- Google- és jelszavas bejelentkezés
- Szerepköralapú jogosultságkezelés

## Technológiák

Next.js 15, React 19, TypeScript, Prisma 7, PostgreSQL, Auth.js,
Tailwind CSS, Shadcn UI, Recharts és Resend.
